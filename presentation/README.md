# Презентация «Сбер — стейкхолдеры, коммуникационные проблемы и PR-решения»

Курс «Теория и практика связей с общественностью» (ТПСО). 11 слайдов в фирменном
стиле Сбера, весь текст — на слайдах (под формат без устной защиты).

## Готовый файл

**`Сбер_ТПСО_презентация.pptx`** — открывается и редактируется в PowerPoint,
«Google Презентациях» и LibreOffice Impress. Весь текст — обычные текстовые блоки,
их можно свободно править.

### Что заполнить вручную
На титульном слайде замените `[ Ваше имя ]` и `[ факультет, группа ]` на свои данные.

### Про шрифт
Текст набран шрифтом **Calibri** (есть в большинстве систем). Фирменный шрифт Сбера —
*SB Sans Text / Sber Sans*; если он у вас установлен, можно выделить весь текст и
заменить шрифт на него для 100% соответствия бренду.

## Как пересобрать (необязательно)

Если захочется менять не текст, а саму вёрстку/картинки:

```bash
npm install                 # pptxgenjs, react-icons, sharp и пр.
pip install Pillow numpy    # для генерации фоновых ассетов
python3 gen_assets.py       # → assets/ (градиентный логотип-знак, тёмный фон)
node build.js               # → Сбер_ТПСО_презентация.pptx
```

## Структура

```
build.js                      — сборка слайдов (правка вёрстки и текста в коде)
gen_assets.py                 — генерация фирменного знака и тёмного градиентного фона
render_preview.py             — превью .pptx → PNG для самопроверки (LibreOffice в этой среде недоступен)
assets/sber_mark.png          — градиентный логотип-знак (зелёный→жёлтый→голубой)
assets/bg_dark.png            — тёмный градиентный фон (титул и финал)
Сбер_ТПСО_презентация.pptx    — готовая презентация
```
