# Презентация «Сбер» — ТПСО

Презентация по предмету «Теория и практика связей с общественностью».
Тема: стейкхолдеры, коммуникационные проблемы и PR-решения Сбера. 11 слайдов.

## Файлы

- **`sber-presentation.pptx`** — редактируемая презентация PowerPoint (11 слайдов). Открывается и правится в PowerPoint, Google Slides, «МойОфис», LibreOffice Impress. Весь текст — обычные текстовые блоки, иконки и карточки — отдельные объекты. Есть плавный переход между слайдами (затемнение).
- **`sber-presentation.html`** — версия с расширенными анимациями и переходами. Открывается двойным кликом в любом браузере (Chrome, Edge, Yandex, Safari). Работает офлайн.
- **`sber-presentation.pdf`** — статичная копия (11 страниц) на случай, если в вуз нужно загрузить файл без анимаций.

## Правка PPTX

- Шрифт — Segoe UI (стандартный для Windows/Office). Если открываете на другом устройстве и шрифт подставился — можно выбрать любой геометричный без засечок (Manrope, Montserrat, Inter).
- Цифры, плашки и иконки можно двигать и удалять как обычные объекты.
- Заголовки набраны фирменным зелёным градиентом Сбера; он отображается в PowerPoint и Google Slides.

## Как показывать (HTML)

- **→ / ← / Space / PageUp / PageDown** — листать слайды
- **F** — на весь экран (рекомендуется для показа)
- **Home / End** — первый / последний слайд
- Можно листать **стрелками на экране**, кликом по краям или свайпом на телефоне

## Перед сдачей

- На титульном слайде намеренно оставлено только слово **Сбер**. Если для сдачи нужны имя/группа — добавьте текстовый блок на первый слайд (в PPTX) или строку в начале первого слайда (в HTML).
- Если после правок HTML нужен свежий PDF — откройте HTML в Chrome → **Печать** (Ctrl/Cmd+P) → «Сохранить как PDF», размер страницы «по источнику», фоновую графику включить.

## Стиль

Фирменная палитра Сбера: зелёный → бирюзовый → жёлтый градиент, чистая типографика, скруглённые карточки, плавные переходы между слайдами и появление элементов. Весь текст содержится в слайдах — защита не требуется.
