# 🍸 Бар-крол по Китай-городу

Путеводитель-игра по барам Китай-города (Москва) для тёплой компании (≈15 человек).
PWA-сайт в стиле тёмного **liquid glass**: открывается по ссылке, ставится на главный
экран телефона, работает офлайн (кроме карты).

## Экраны

- **Старт** — заставка с кнопкой «Начать».
- **🗺️ Карта** — бары на Яндекс.Картах (тёмная тема), тапаешь по пину → карточка бара.
- **🧭 Маршрут** — собираешь последовательность баров на вечер и ставишь **таймер на
  каждый бар**: обратный отсчёт, сигнал + вибрация по окончании, кнопка «следующий бар».
- **⭐ Оценки** — сюда попадают бары, которым ты поставил звёзды.
- **🎫 Паспорт** — кольцо прогресса, рейтинг и **шуточное звание** по числу посещённых
  баров (отмечаешь их кнопкой «Были тут» в карточке).
- **Карточка бара** — описание от автора, что заказать / что **не** стоит заказывать,
  квест-задание, локальная оценка звёздами, «Были тут», добавить в маршрут.

Всё локально (`localStorage`): оценки, посещения, маршрут и таймер у каждого свои.

## 🔑 Ключ Яндекс.Карт (обязательно для карты)

Карта работает на **Яндекс.Картах (JavaScript API v3)** — нужен бесплатный ключ:

1. Открой <https://yandex.ru/dev/jsapi-v3/> → **«Получить ключ»** (нужен аккаунт Яндекса).
2. Создай ключ для **JavaScript API v3** (бесплатно).
3. Вставь его в `js/config.js` в поле `YANDEX_API_KEY`.

Без ключа всё приложение работает, но на вкладке «Карта» будет подсказка и список баров
со ссылками на маршрут в Яндекс.Картах. После добавления ключа карта появится сама.

## Запуск локально

Нужен любой статический сервер (service worker не работает с `file://`):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой (бесплатно)

Подходит **GitHub Pages**: Settings → Pages → Deploy from branch → ветка → корень `/`.
После этого кидаешь ссылку друзьям.

## Как поменять бары

Все бары — в `js/data.js`, массив `BARS` (сейчас заглушки с реальными координатами улиц
Китай-города). У каждого бара: `name`, `street`, `coords` `[широта, долгота]`, `feature`
(описание), `order` (что заказать), `avoid` (что не стоит), `quest` (задание), `toast`,
`photo` (пока пусто — добавим фото позже).

## Структура

```
index.html              — разметка (старт, вкладки, карточка)
css/styles.css          — стили (тёмный liquid glass)
js/config.js            — ключ Яндекс.Карт и настройки
js/data.js              — данные баров (правь здесь)
js/app.js               — логика: карта, маршрут, таймер, оценки, паспорт
manifest.webmanifest    — PWA-манифест
sw.js                   — service worker (офлайн-оболочка)
icons/icon.svg          — иконка
```

## Заметки

- Оценки **локальные**: у каждого свои, между телефонами не синхронизируются. При желании
  позже можно добавить общий бэкенд (Firebase/Supabase) для среднего балла.
- Карта и её тайлы грузятся из сети — для карты нужен интернет.
