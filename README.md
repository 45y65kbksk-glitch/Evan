# 🍻 Бар-крол по Китай-городу

Путеводитель-игра по барам Китай-города (Москва) для тёплой компании.
PWA-сайт: открывается по ссылке, можно добавить на главный экран телефона.

## Что внутри

- **Маршрут** — список баров по порядку обхода с прогрессом.
- **Карта** — точки баров на бесплатной OpenStreetMap (Leaflet), линия маршрута, навигация.
- **Карточка бара** — зачем идти, что заказать, челлендж + тост, оценка звёздами, отметка «были тут».
- **Паспорт** — кольцо прогресса и бейджи за пройденные точки.
- **Локальное хранение** — оценки и галочки сохраняются в браузере (`localStorage`), у каждого свои, работают офлайн.

## Запуск локально

Нужен любой статический сервер (service worker не работает с `file://`):

```bash
# Python
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой (бесплатно)

Подходит **GitHub Pages**: Settings → Pages → Deploy from branch → корень репозитория.
После этого кидаешь ссылку друзьям.

## Как поменять бары

Все бары — заглушки в `js/data.js` (названия вымышленные, координаты стоят
на реальных улицах Китай-города). Отредактируй массив `BARS`: название,
улицу, координаты `[широта, долгота]`, фишку, что заказать, челлендж и тост.

## Структура

```
index.html              — разметка
css/styles.css          — стили (тёмная «барная» тема)
js/data.js              — данные баров (правь здесь)
js/app.js               — логика, карта, рейтинги, паспорт
manifest.webmanifest    — PWA-манифест
sw.js                   — service worker (офлайн-оболочка)
icons/icon.svg          — иконка
```

## Заметки

- Рейтинг **локальный**: оценки друзей не синхронизируются между телефонами.
  Архитектуру позже можно расширить общим бэкендом (Firebase/Supabase),
  если захочется общий средний балл.
- Тайлы карты подгружаются из сети — для карты нужен интернет.
